# Python Programming

파이썬 문법부터 데이터베이스, Open API, 웹 앱, AI 모델 활용까지 단계별로 실습하는 학습 저장소입니다. 대부분의 예제는 폴더별 독립 실행 파일로 구성되어 있어, 관심 있는 주제의 코드를 하나씩 실행하고 수정해 볼 수 있습니다.

## 실행 방법

1. 저장소를 내려받고 프로젝트 폴더로 이동합니다.
2. 예제를 실행할 Python 환경을 준비합니다.
3. 저장소 루트에서 원하는 스크립트를 실행합니다. 예를 들면:

   ```powershell
   python .\01_datatype\ex1.py
   ```

예제별로 필요한 라이브러리가 다릅니다. 스크립트의 import 문과 주석에 적힌 설치 안내를 확인한 뒤 해당 라이브러리를 설치하세요. 데이터베이스 예제는 실행 과정에서 SQLite 파일을 사용하거나 생성할 수 있습니다.

### 급식 조회 앱 실행

`13_openapi_project`는 날짜별 급식 정보를 조회하는 Streamlit 앱입니다. SQLite에 저장된 정보가 있으면 먼저 사용하고, 없으면 나이스 급식 Open API에서 조회한 뒤 데이터베이스에 저장합니다.

```powershell
cd .\13_openapi_project
streamlit run app.py
```

앱 실행에 필요한 `streamlit`, `pandas`, `requests`, `python-dotenv` 등을 Python 환경에 설치하세요. API 조회를 사용하려면 이 폴더에서 사용하는 환경 변수와 API 키를 준비해야 합니다.

### AI 예제

`14_ai`에는 다음 순서의 Hugging Face 실습이 있습니다.

| 파일 | 내용 |
| --- | --- |
| `ex1.py` | 사전 학습 텍스트 파이프라인: 분류, 빈칸 채우기, 텍스트 생성 |
| `ex2.py`–`ex3.py` | 텍스트 분류 모델 파인 튜닝과 저장한 모델 사용 |
| `ex4.py`–`ex5.py` | 텍스트 생성 모델 파인 튜닝과 저장한 모델 사용 |
| `ex6.py` | 사전 학습 이미지 분류 파이프라인 |
| `ex7.py`–`ex8.py` | 이미지 분류 모델 파인 튜닝과 저장한 모델 사용 |

AI 실습에는 `transformers`, `torch`가 사용되며, 이미지 예제에는 `pillow`와 `torchvision`도 필요할 수 있습니다. 모델을 처음 불러올 때 다운로드가 발생할 수 있고, 파인 튜닝에는 추가 시간과 메모리·연산 자원이 필요합니다. `data`, `dataset`, `images` 폴더에는 실습용 데이터와 이미지가 들어 있습니다. 학습을 먼저 실행해야 사용할 수 있는 예제는 해당 모델 파일이 생성된 뒤 실행하세요.

## API 키와 보안

API 키나 Hugging Face 토큰이 필요한 예제는 각 스크립트가 읽는 환경 변수 이름을 확인하고 로컬 환경에 설정하세요. 토큰 값은 소스 코드나 공개 저장소에 입력하거나 공유하지 마세요.

## 저장소의 다른 파일

- `python_project`: 도시 정보 API와 데이터베이스를 사용하는 별도 프로젝트 예제
- `AutoCommitPush.exe`, `auto-commit-push.py`: 저장소 변경 사항의 자동 커밋·푸시를 위한 Windows 프로그램과 소스

학습 자료와 실행 환경은 계속 추가·변경될 수 있으므로, 각 예제의 코드 주석을 함께 확인하세요.
